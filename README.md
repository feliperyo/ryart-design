# 🌐 Site Oficial de Portfólio e Serviços – RyArt Design  

Este repositório contém o código do **site oficial de portfólio e serviços digitais da RyArt Design**.  
O projeto reúne trabalhos de design gráfico, identidade visual e soluções completas de desenvolvimento web, além de apresentar os serviços oferecidos pela marca.  

## 🎯 Objetivo do Projeto  
Criar um espaço digital que funcione como portfólio e vitrine de serviços, unindo **design criativo** e **tecnologia de ponta** para entregar soluções de impacto.  

## 🚀 Destaques  
- 🎨 Galeria com projetos de design gráfico, capas de singles, artes digitais e logos animados  
- 💻 Exemplos de sites responsivos, layouts e sistemas completos  
- 📈 Apresentação dos serviços oferecidos pela RyArt Design  

## 🛠️ Tecnologias Utilizadas

- **CSS3** – Estilização responsiva
